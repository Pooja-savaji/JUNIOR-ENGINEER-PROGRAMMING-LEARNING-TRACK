# 1 DataFrames

## About
This topic introduces the basic data structures and operations used in Pandas. It focuses on working with Series and DataFrames, loading data, understanding data types, selecting data, and inspecting datasets.

## Concepts Covered
* Series
* DataFrame
* Loading data
* Data types (`dtypes`)
* Indexing
* Column selection
* Row selection
* Data inspection
* Basic DataFrame operations

## What I Learned
* A Series is a one-dimensional Pandas data structure.
* A DataFrame is a two-dimensional table of rows and columns.
* Data can be loaded from files such as CSV and Excel.
* `dtypes` shows the data type of each column.
* Indexing is used to access specific rows and columns.
* Columns and rows can be selected using different Pandas methods.
* DataFrame inspection helps understand the structure and contents of a dataset.

## Learning Outcomes
After completing this topic, I can:
* Create Series and DataFrames.
* Load data into Pandas.
* Check column data types.
* Select specific rows and columns.
* Inspect the structure and contents of a dataset.
* Perform basic DataFrame operations using Pandas.
