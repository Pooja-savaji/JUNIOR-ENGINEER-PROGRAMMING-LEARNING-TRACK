# 6.4 Excel Workbooks

## About
This topic introduces working with Excel workbooks using Python and OpenPyXL. It focuses on reading and writing worksheets, handling formulas and values, applying basic formatting, and organizing workbook structure.

## Concepts Covered
* Reading Excel workbooks
* Reading worksheets
* Writing worksheets
* Adding and updating cells
* Formulas and values
* Cell formatting
* Workbook structure
* Using OpenPyXL when needed

## What I Learned
* Excel workbooks can contain multiple worksheets.
* OpenPyXL can be used to read and modify Excel files.
* Data can be read from specific sheets and cells.
* New sheets and values can be added to a workbook.
* Formulas and calculated values need to be handled carefully.
* Cells can be formatted using fonts, alignment, borders, and number formats.
* A well-organized workbook makes reports easier to read and maintain.

## Learning Outcomes

After completing this topic, I can:
* Read data from Excel worksheets using OpenPyXL.
* Create and update Excel worksheets.
* Write values and formulas into cells.
* Apply basic formatting to Excel reports.
* Understand the structure of an Excel workbook.
* Use OpenPyXL when Excel-specific operations are required.
* Create simple and organized Excel reports using Python.
