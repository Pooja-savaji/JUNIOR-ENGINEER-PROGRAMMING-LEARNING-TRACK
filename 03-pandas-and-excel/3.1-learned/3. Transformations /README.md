# 6.3 Transformations

## About
This topic introduces common data transformation techniques in Pandas. It focuses on filtering, sorting, grouping, combining datasets, creating summaries, and adding calculated columns.

## Concepts Covered
* Filtering data
* Sorting data
* `groupby()`
* Aggregation
* Merge and Join
* Pivot tables
* Calculated columns
* Data transformation

## What I Learned
* Filtering helps select only the required rows.
* Sorting arranges data based on one or more columns.
* `groupby()` organizes data into groups for analysis.
* Aggregation calculates summaries such as sum, mean, count, minimum, and maximum.
* Merge and join combine data from different DataFrames.
* Pivot tables summarize data in a structured format.
* Calculated columns can be created using existing data.
* Transformations help prepare data for analysis and reporting.

## Learning Outcomes
After completing this topic, I can:
* Filter and sort DataFrame data.
* Group data using `groupby()`.
* Perform basic aggregations.
* Merge and join multiple DataFrames.
* Create pivot tables for summaries.
* Create calculated columns.
* Transform datasets into useful formats for analysis.
