# 6.5 Validation

## About
This topic introduces data validation techniques used to check whether a dataset is complete, correct, and consistent. Validation helps identify problems before the data is used for analysis or reporting.

## Concepts Covered
* Schema checks
* Required columns
* Valid ranges
* Duplicate keys
* Error reports
* Data quality checks

## What I Learned
* Schema checks verify the expected structure of a dataset.
* Required columns make sure important fields are present.
* Valid ranges help identify values outside the expected limits.
* Duplicate keys can cause incorrect or repeated records.
* Error reports help clearly identify validation problems.
* Validation should be performed before using data for analysis.
* Good validation improves data quality and reliability.

## Learning Outcomes

After completing this topic, I can:
* Check whether a dataset has the expected structure.
* Verify that required columns are present.
* Check values against valid ranges.
* Detect duplicate keys.
* Identify invalid or missing data.
* Create simple error reports.
* Validate data before analysis or reporting.
