 Data Processing Assumptions

- Required columns are Name, Age, and Salary.
- Age must be a valid number.
- Salary must be greater than 0.
- Missing or invalid values are reported as errors.
- Annual Salary is calculated as Monthly Salary × 12.
- The original input data is not modified.
- The final report is saved as an Excel workbook.
- Validation errors are stored in the Error Summary sheet.
