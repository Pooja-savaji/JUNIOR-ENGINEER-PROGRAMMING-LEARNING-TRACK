# 12.1 Test Basics

## About
This topic introduces the basics of testing Python programs using simple test cases and assertions.

## Topics Covered
* Test discovery
* Assertions
* Test functions
* Utilities testing
* Validation testing
* Basic test organization

## What I Practiced
* Created a simple calculator utility.
* Created a simple age validator.
* Wrote tests for the calculator.
* Wrote tests for valid and invalid ages.
* Used `assert` to check expected results.
* Organized code and test files separately.

## Learning Goals
* Understand the purpose of testing.
* Learn how to write simple test cases.
* Learn how to use assertions.
* Practice testing utilities and validators.
* Create readable and organized tests.
