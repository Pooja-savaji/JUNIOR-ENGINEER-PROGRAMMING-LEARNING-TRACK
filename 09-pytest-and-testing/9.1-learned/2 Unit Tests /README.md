# 12.2 Unit Tests

## About
This topic focuses on writing simple unit tests for a small Python module. The tests check normal inputs, boundary cases, and invalid inputs.

## Topics Covered
* Pure functions
* Boundary testing
* Invalid inputs
* Deterministic behavior
* Meaningful test coverage
* Behavior-based testing

## What I Practiced
* Created a small calculator module.
* Tested addition and division.
* Tested even and odd numbers.
* Tested zero as a boundary case.
* Tested division by zero as an invalid input.
* Used `pytest` to check expected behavior.

## Learning Goals
* Understand the basics of unit testing.
* Learn how to test important input cases.
* Learn how to test invalid inputs.
* Understand boundary testing.
* Write tests that verify behavior rather than implementation details.
