# 12.5 Integration Tests

## About
This topic focuses on testing how a repository works with a real SQLite database.

## Topics Covered
* Integration testing
* Database testing
* Repository testing
* Real component interaction
* Test database
* Unit vs integration tests

## What I Practiced
* Created a temporary SQLite database.
* Created a simple user repository.
* Saved a user to the database.
* Retrieved the user from the database.
* Tested the repository and database together.
* Used a controlled test database.

## Learning Goals
* Understand integration testing.
* Learn how repositories interact with databases.
* Practice testing real component connections.
* Understand the difference between unit and integration tests.
* Identify whether a failure comes from a component or its integration.
