# 12.4 Mocking

## About
This topic introduces mocking by using a fake repository to test a service without connecting to a real database or external service.

## Topics Covered
* Mocking
* Fake dependencies
* API and repository testing
* External dependencies
* Testing service behavior
* What to mock and what not to mock

## What I Practiced
* Created a simple user service.
* Created a fake user repository.
* Used the fake repository in a test.
* Tested the service without using a real database.
* Checked the returned user data.

## Learning Goals
* Understand the purpose of mocking.
* Learn how to replace external dependencies during testing.
* Practice testing services with fake dependencies.
* Understand what should and should not be mocked.
* Write simple and reliable tests.
