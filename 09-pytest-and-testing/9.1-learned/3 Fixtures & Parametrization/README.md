# 12.3 Fixtures & Test Data

## About
This topic focuses on using reusable fixtures and test data to make Python tests simple and less repetitive.

## Topics Covered
* Reusable fixtures
* Parameterized test cases
* Test data
* Reusing test data
* Reducing repetitive test code

## What I Practiced
* Created a simple student marks validator.
* Created reusable marks using a fixture.
* Tested different marks.
* Used parameterized tests for multiple test cases.
* Reused test data instead of writing it repeatedly.

## Learning Goals
* Understand how fixtures work.
* Learn how to reuse test data.
* Learn how to test multiple cases with one test.
* Reduce repetitive test code.
* Write simple and readable tests.
