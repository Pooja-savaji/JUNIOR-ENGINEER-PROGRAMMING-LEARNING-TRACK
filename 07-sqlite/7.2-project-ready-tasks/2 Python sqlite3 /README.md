# Task 10.2 — Python sqlite3

## About
This task covers basic database operations using Python's `sqlite3` module.

## Concepts Covered

* Database Connections
* Cursors
* Parameterized Queries
* Transactions
* Row Mapping
* CRUD Operations

## CRUD Operations

* Create — Add data
* Read — Get data
* Update — Modify data
* Delete — Remove data

## What I Practiced
I practiced connecting Python with SQLite, executing SQL queries using a cursor, using `?` placeholders for safe queries, committing transactions, and performing CRUD operations.
This task helped me understand how Python applications work with databases safely.
