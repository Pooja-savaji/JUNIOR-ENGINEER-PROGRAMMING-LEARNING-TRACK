# Task 10.3 — Schema Design

## About
This task covers the basics of designing a database schema for a multi-table application.

## Concepts Covered

* Normalization
* Primary Keys
* Foreign Keys
* Relationships
* Indexes
* Constraints
* Timestamps
* Migrations

## What I Practiced
I designed a simple application database using multiple related tables.
I practiced choosing primary keys, connecting tables using foreign keys, adding constraints, and understanding one-to-many relationships.
I also learned how indexes improve searching and how migrations are used to safely change database structure.

## Learning Goal
I should be able to:

* Design related tables
* Choose suitable primary keys
* Use foreign keys
* Explain table relationships
* Add basic constraints
* Understand indexes
* Understand database migrations
