## 10.1 SQL Basics
## What I Learned
 
1. Tables:
A table stores data in rows and columns.

 2. Primary Key:
A primary key uniquely identifies each record in a table.

3. Foreign Key:
A foreign key connects one table with another table.

4. SELECT:
Used to read data from a table.

5. INSERT:
Used to add new records.

 6. UPDATE:
Used to modify existing records.

7. DELETE :
Used to remove records.

 8. WHERE:
Used to filter records based on a condition.

9. JOIN:
Used to combine data from two or more related tables.

 10. GROUP BY:
Used to group records and perform calculations such as COUNT or SUM.


## Learning Goal
I should be able to:
* Create tables
* Define primary and foreign keys
* Insert records
* Read records using SELECT
* Filter records using WHERE
* Update records
* Delete records
* Join related tables
* Group data using GROUP BY
* Write basic SQL queries independently
