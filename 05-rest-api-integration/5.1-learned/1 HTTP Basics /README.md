# 8.1 HTTP Basics

## About
This module introduces the basic concepts of HTTP communication used in web applications and APIs. I practiced how HTTP requests are structured and how clients and servers exchange data.

## Topics Covered
* HTTP methods: GET, POST, PUT, PATCH, DELETE
* URLs and URL structure
* HTTP request and response headers
* HTTP status codes
* JSON data
* Query parameters
* Path parameters
* Body parameters
* Basic HTTP request and response structure

# What I Practiced
* Created examples using different HTTP methods.
* Identified different parts of a URL.
* Practiced reading common HTTP status codes.
* Created and understood simple JSON data.
* Practiced using query parameters for filtering and searching.
* Practiced using path parameters to identify specific resources.
* Practiced sending data through request bodies.
* Analyzed basic HTTP request and response structures.

## Learning Goals
* Understand how HTTP communication works.
* Know when to use common HTTP methods.
* Understand URLs, headers, and status codes.
* Understand how data is represented using JSON.
* Differentiate between query, path, and body parameters.
* Be able to read and design basic HTTP requests and responses.
* Build a foundation for working with REST APIs.
