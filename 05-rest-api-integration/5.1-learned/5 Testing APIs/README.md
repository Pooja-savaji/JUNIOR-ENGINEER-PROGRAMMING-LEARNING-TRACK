# 8.5 Testing APIs

## About
This module introduces the basics of testing APIs. I practiced testing API behavior without depending on real external services by using mocked HTTP calls and fixture responses.

## Topics Covered
* API testing basics
* Mocking HTTP calls
* Fixture responses
* Testing successful API responses
* Testing API errors
* Contract-oriented tests
* Request and response validation

## What I Practiced
* Created tests for API client functions.
* Mocked HTTP requests instead of calling real APIs.
* Created fixture responses for testing.
* Tested successful API responses.
* Tested invalid and error responses.
* Checked returned status codes and JSON data.
* Practiced validating expected request and response structures.
* Created basic contract-oriented tests to verify that an API follows an expected format.

## Learning Goals
* Understand why APIs need automated tests.
* Test API clients without depending on external services.
* Use mocks to simulate HTTP responses.
* Use fixtures for repeatable test data.
* Test both successful and failed API requests.
* Validate expected request and response structures.
* Build reliable and maintainable API tests.
