# 8.4 Error Handling

## About
This module introduces common errors that can occur when working with APIs and HTTP requests. I practiced handling connection problems, timeouts, retries, rate limits, invalid responses, and displaying safe error messages to users.

## Topics Covered
* Timeouts
* Retries
* Rate limits
* Invalid responses
* Connection failures
* HTTP errors
* User-safe error messages
* Basic API error handling

## What I Practiced
* Added timeouts to HTTP requests.
* Practiced retrying failed requests.
* Handled API rate-limit responses.
* Checked and handled invalid API responses.
* Handled connection failures.
* Checked HTTP status codes before processing responses.
* Prevented technical error details from being shown directly to users.
* Created simple and user-friendly error messages.
* Practiced handling different API failure situations.

## Learning Goals
* Understand common API and HTTP errors.
* Handle request timeouts and connection failures.
* Understand when and how retries are used.
* Handle API rate limits safely.
* Detect invalid responses.
* Check HTTP errors correctly.
* Display clear and user-safe error messages.
* Build more reliable API clients.
