# 8.2 Python HTTP Client

## About
This module introduces how Python programs communicate with web APIs using HTTP clients. I practiced sending requests, receiving responses, handling JSON data, setting timeouts, and checking errors.

## Topics Covered
* Python HTTP clients
* `requests` basics
* `httpx` basics
* GET and POST requests
* Request parameters
* Request headers
* JSON request and response handling
* Timeouts
* HTTP status code checks
* Basic error handling

## What I Practiced
* Sent GET requests using Python.
* Sent POST requests with JSON data.
* Used query parameters and headers.
* Read JSON responses from APIs.
* Converted API responses into Python data.
* Used timeouts to prevent requests from waiting indefinitely.
* Checked HTTP status codes.
* Handled basic request errors.
* Practiced making API calls using both `requests` and `httpx`.

## Learning Goals
* Understand how to make HTTP requests from Python.
* Use `requests` and `httpx` for basic API communication.
* Send parameters, headers, and JSON data.
* Read and process JSON API responses.
* Use timeouts in HTTP requests.
* Check HTTP status codes and handle basic errors.
* Build a foundation for working with APIs in Python.
