# 5.2 Encapsulation

## About
Encapsulation is an Object-Oriented Programming concept used to protect and control access to data inside a class. It helps keep data safe and allows changes only through defined methods or properties.

## Concepts Covered
* Public attributes
* Private attributes
* Naming conventions
* Properties
* Getters and setters
* Data validation
* Controlled state changes

## What I Learned
* Public attributes can be accessed directly.
* Private attributes are written using `_` or `__` naming conventions.
* Properties can control how data is accessed and changed.
* Validation helps prevent invalid data.
* State changes should be controlled through methods or properties.
* Encapsulation helps keep class data organized and protected.

## Learning Outcomes
After completing this topic, I can:
* Use public and private attribute conventions.
* Create properties for controlled access to data.
* Add validation before changing object data.
* Prevent invalid values from being stored.
* Control how the state of an object can be changed.
* Write simple and maintainable encapsulated classes.
