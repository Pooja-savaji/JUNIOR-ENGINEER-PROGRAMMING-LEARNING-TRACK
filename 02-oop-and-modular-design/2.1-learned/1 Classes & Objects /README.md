# 5.1 Classes & Objects

## About
This topic introduces the basic concepts of Object-Oriented Programming (OOP) in Python. It explains how to create classes and objects and how to work with data and functions inside a class.

## Concepts Covered
* Classes
* Objects / Instances
* Attributes
* Methods
* Constructors (`__init__`)
* Class Methods
* Static Methods
* Properties

## What I Learned
* A class is a blueprint for creating objects.
* An object is an instance of a class.
* Attributes store data inside objects.
* Methods perform actions using object data.
* The `__init__()` constructor initializes object data.
* Class methods work with class-level data.
* Static methods perform independent operations.
* Properties provide controlled access to object data.

## Learning Outcomes
After completing this topic, I can:
* Create simple Python classes and objects.
* Define attributes and methods.
* Use constructors to initialize objects.
* Understand the difference between instance, class, and static methods.
* Use properties to access object data.
* Write simple and readable OOP-based Python programs.
