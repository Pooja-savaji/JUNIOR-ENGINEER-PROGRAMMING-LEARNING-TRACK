# 5.4 Interfaces & Abstraction

## About
This topic introduces abstraction and interface concepts in Python. It explains how to define what a class should do without focusing on how it does it, and how different implementations can be used interchangeably.

## Concepts Covered
* Abstraction
* Abstract Base Classes (ABC)
* Abstract methods
* Interfaces
* Protocols
* Dependency boundaries
* Interchangeable implementations

## What I Learned
* Abstraction hides unnecessary implementation details.
* An interface defines the expected behavior of a class.
* `ABC` can be used to create abstract base classes.
* Abstract methods define methods that child classes must implement.
* Protocols describe the expected structure and behavior of an object.
* Dependency boundaries help separate different parts of an application.
* Different classes can provide the same behavior in different ways.

## Learning Outcomes
After completing this topic, I can:
* Create simple abstract classes using `ABC`.
* Define and implement abstract methods.
* Understand the basic concept of interfaces and protocols.
* Create clear boundaries between components.
* Use different implementations through the same interface.
* Design simple and flexible OOP-based programs.
