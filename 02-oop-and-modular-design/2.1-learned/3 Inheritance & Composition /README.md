# 5.3 Inheritance & Composition

## About
This topic introduces inheritance and composition in Object-Oriented Programming. It explains how classes can reuse behavior from other classes and how objects can be combined to build flexible programs.

## Concepts Covered
* Inheritance
* Parent and child classes
* Method overriding
* Reusing class behavior
* Abstract behavior
* Composition
* Inheritance vs Composition
* When composition is preferable

## What I Learned
* Inheritance allows a child class to reuse features of a parent class.
* A child class can override a parent class method.
* Abstract behavior defines what a class should do without providing the complete implementation.
* Composition means using one object inside another object.
* Inheritance represents an **"is-a"** relationship.
* Composition represents a **"has-a"** relationship.
* Composition can be preferable when objects need to work together without creating a strict parent-child relationship.

## Learning Outcomes
After completing this topic, I can:

* Create parent and child classes.
* Use inheritance to reuse code.
* Override methods in child classes.
* Understand basic abstract behavior.
* Use composition to combine objects.
* Identify when inheritance or composition is more suitable.
* Design simple and reusable OOP structures.
