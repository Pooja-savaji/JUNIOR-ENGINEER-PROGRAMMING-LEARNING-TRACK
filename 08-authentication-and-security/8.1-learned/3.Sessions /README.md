# 8.3 Sessions

## About
This topic introduces the basic concepts of sessions in web applications. It explains how login sessions are created, managed, expired, and used to control access.

## Concepts Covered
- Login
- Logout
- Session Expiry
- Authorization Checks
- Secure State Handling

## What I Learned

- Login creates a session after the user's credentials are verified.
- Logout ends the user's session.
- Session expiry automatically ends a session after a certain time or inactivity.
- Authorization checks ensure that users can only access resources they have permission to use.
- Session information should be handled securely to prevent unauthorized access.

## Learning Outcomes
After completing this topic, I can:

- Understand how login and logout sessions work.
- Understand session expiry.
- Perform basic authorization checks.
- Understand the importance of secure session handling.
- Protect pages and resources from unauthorized users.
