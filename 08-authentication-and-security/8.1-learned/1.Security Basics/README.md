## About
This topic introduces the basic concepts of application security. It explains how to protect data, control access, and identify common security risks.

## Concepts Covered

- Confidentiality
- Integrity
- Availability
- Least Privilege
- Trust Boundaries
- Threat Awareness
- Common Security Risks

## What I Learned

- Confidentiality protects sensitive information from unauthorized access.
- Integrity ensures data is not changed without permission.
- Availability keeps applications and services accessible.
- Least privilege gives users only the permissions they need.
- Trust boundaries help identify trusted and untrusted data.
- Threat awareness helps identify possible security attacks.
- Common risks include weak passwords, SQL injection, hardcoded secrets, and unauthorized access.

## Learning Outcomes

After completing this topic, I can:

- Understand basic application security principles.
- Identify common security weaknesses.
- Recognize trusted and untrusted data.
- Apply the principle of least privilege.
- Identify basic security risks and suggest suitable fixes.
