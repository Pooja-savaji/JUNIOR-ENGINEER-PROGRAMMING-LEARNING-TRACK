# 8.2 Password Security

## About
This topic introduces the basic concepts of password security. It explains how passwords should be stored and verified securely without storing them as plain text.

## Concepts Covered
- Password Hashing
- Salts
- Password Verification
- Secure Password Storage
- Plaintext Passwords

## What I Learned
- Hashing converts a password into a secure, unreadable value.
- A salt is a random value added to a password before hashing.
- Password verification checks whether the entered password matches the stored password hash.
- Passwords should never be stored as plaintext.
- Secure password storage helps protect user accounts if the database is compromised.

## Learning Outcomes
After completing this topic, I can:

- Understand how password hashing works.
- Understand the purpose of salts.
- Explain how passwords are verified during login.
- Understand why plaintext passwords should never be stored.
- Follow basic secure password storage practices.
