# 8.4 Secrets & Configuration

## About
This topic introduces the basic concepts of managing secrets and application configuration securely. It explains how to keep sensitive information separate from source code and logs.

## Concepts Covered
- Environment Variables
- Secret Stores
- Configuration Separation
- Safe Logging
- Secure Secret Management

## What I Learned

- Environment variables can store sensitive values such as API keys and passwords.
- Secret stores provide a secure place to manage sensitive information.
- Configuration should be separated from application code.
- Passwords, API keys, and tokens should not be written directly in source code.
- Sensitive information should never be exposed in application logs.

## Learning Outcomes
After completing this topic, I can:

- Use environment variables for configuration and secrets.
- Understand the purpose of secret stores.
- Keep secrets separate from application code.
- Avoid exposing sensitive information in logs.
- Follow basic secure configuration practices.
