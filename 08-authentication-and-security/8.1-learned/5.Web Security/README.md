# 8.5 Web/API Security

## About
This topic introduces the basic security concepts used in web applications and APIs. It explains how to protect communication, user input, APIs, and web applications from common attacks.

## Concepts Covered
- HTTPS
- Tokens
- Security Headers
- Input Validation
- Injection
- CSRF
- XSS
- Dependency Hygiene

## What I Learned

- HTTPS encrypts communication between the client and server.
- Tokens are used to authenticate and authorize API requests.
- Security headers provide additional protection for web applications.
- Input validation helps prevent invalid and harmful data.
- Injection attacks can occur when untrusted input is used unsafely.
- CSRF can trick users into performing unwanted actions.
- XSS can inject harmful scripts into web pages.
- Dependencies should be kept updated and checked for security vulnerabilities.

## Learning Outcomes
After completing this topic, I can:

- Understand how HTTPS protects data.
- Understand the purpose of API tokens and security headers.
- Validate user input before processing it.
- Recognize basic injection, CSRF, and XSS risks.
- Keep application dependencies updated and secure.
