# Broken Application Diagnosis

## About
This project practices debugging a broken Python application, identifying root causes, fixing defects, and testing the fixes.

## Concepts Covered
- Debugging and tracebacks
- Root cause analysis
- File handling and configuration
- Error handling
- Unit testing

## What I Learned
- Collect evidence before fixing errors.
- Identify the actual cause of each defect.
- Fix problems and verify the results.
- Write a diagnosis report.

## Learning Outcomes
- Debug an unfamiliar application.
- Separate symptoms from root causes.
- Test fixes and prevent repeated defects.

## How to Run
1.python -m src.app

2.python -m unittest discover -s tests
