## About
Learned a systematic debugging method to find, fix, and prevent software problems.

## Concepts Covered

- Reproduce
- Isolate
- Hypothesize
- Inspect Evidence
- Fix
- Verify
- Prevent Recurrence

## What I Learned

- Reproduced errors to understand the problem.
- Isolated the part of the code causing the issue.
- Identified possible causes of the error.
- Checked error messages, logs, and variables.
- Applied fixes to resolve the problem.
- Tested the fix to verify the result.
- Added tests or validation to prevent the same issue again.

## Learning Outcomes

- Understand a systematic debugging process.
- Identify the root cause of errors.
- Use evidence to troubleshoot problems.
- Fix and verify software defects.
- Write tests to prevent recurring bugs.
- Debug problems independently.
