## About
Learned how to find the real cause of a problem and prevent it from happening again.

## Concepts Covered

- Symptom vs Root Cause
- Minimal Reproduction
- Corrective Action
- Regression Test

## What I Learned

- Identify the visible problem.
- Find the actual root cause.
- Reproduce the problem in a simple way.
- Apply the correct fix.
- Add tests to prevent the problem from returning.

## Learning Outcomes

- Understand root cause analysis.
- Find the real cause of bugs.
- Fix problems correctly.
- Create regression tests.
- Prevent repeated issues.
