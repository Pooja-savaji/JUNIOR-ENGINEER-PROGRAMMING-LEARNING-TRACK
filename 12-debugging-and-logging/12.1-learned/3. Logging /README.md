## About
Learned how to use logging to monitor applications and troubleshoot errors.

## Concepts Covered

- Log Levels
- Structured Context
- Useful Messages
- Exception Logging
- Avoiding Secrets

## What I Learned

- Use different log levels for different situations.
- Add useful information to logs.
- Write clear and meaningful messages.
- Record exception details for debugging.
- Keep passwords and secrets out of logs.

## Learning Outcomes

- Understand application logging.
- Choose the correct log level.
- Create useful logs.
- Record errors safely.
- Avoid exposing sensitive information.
