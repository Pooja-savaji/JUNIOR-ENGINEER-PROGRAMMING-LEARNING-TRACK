## About

## Concepts Covered

- Smoke Tests
- Logs
- Permissions
- Antivirus/Endpoint Considerations
- Rollback Planning

## What I Learned

- Tested basic application functions before release.
- Checked logs to identify errors.
- Verified file and application permissions.
- Understood how antivirus software can affect applications.
- Learned how to restore a previous version if a release fails.

## Learning Outcomes

- Perform basic release validation.
- Identify errors using logs.
- Check application permissions.
- Understand security software issues.
- Plan rollback for failed releases.
