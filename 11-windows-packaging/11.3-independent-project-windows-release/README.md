
# Windows Release Validation

## About
This project practices preparing a Python application for release by creating documentation, testing the application, and validating deployment steps.

## Concepts Covered

- Application architecture
- Installation and deployment
- Automated testing
- Troubleshooting
- Release validation

## What I Learned

- Organize application files properly.
- Write clear installation instructions.
- Test application functionality.
- Identify and resolve common errors.

## Learning Outcomes

- Understand the application structure.
- Install and run the application.
- Execute automated tests.
- Troubleshoot common problems.
- Prepare documentation for handoff.

## How to Run

1. Install dependencies: pip install -r requirements.txt

2. Run the application: python -m src.main

3. Run tests: python -m pytest tests -v
