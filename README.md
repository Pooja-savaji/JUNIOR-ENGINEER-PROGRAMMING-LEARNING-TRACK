# Junior Engineer Programming Learning Track

This repository is my personal study log as I work through Delta IoT Solutions' 2-week Junior Engineer Learning Track. It serves as an independent learning space to build and sharpen my core engineering skills across 14 modules, completely separate from any customer project work.

## How I'm working through this

Each module in this track follows a structured progression:
1. **Learn**: Study the core concepts, understand the theory, and review examples.
2. **Practice**: Work through guided code exercises to build muscle memory and confidence.
3. **Build**: Apply the skills to realistic, project-ready components and integrate them.
4. **Independent Challenge**: Complete standalone unassisted exercises for each topic to verify mastery.
