# Asset Tracker - Junior Engineer Track

A 2-week self-paced junior engineer training project — an Asset Request & Tracking application built incrementally, one skill module per day, following a structured Learned → Project Ready → Independent progression.

## How this repo is organized

- `asset-tracker/`: The main growing application where features and modules are developed step by step.
- `independent-challenges/`: Contains separate unassisted exercises for each skill to reinforce learning independently.
