# 9.2 SharePoint Data Operations

## About
Learned how to perform basic data operations on SharePoint Lists.

## Topics Covered
- Create
- Read
- Update
- Delete (CRUD)
- Filtering
- Field Types
- SharePoint IDs

## What I Practiced
- Added employee records.
- Viewed list items.
- Updated employee information.
- Deleted test records.
- Filtered data by department and training status.
- Used Text, Number, Choice, and Date fields.
- Understood automatically generated SharePoint IDs.

## Key Learning

```text
Create → Add Item
Read   → View Item
Update → Edit Item
Delete → Remove Item
Filter → Find Required Data
ID     → Unique Item Identifier
```

## Outcome
Can perform basic CRUD operations, apply filters, identify field types, and understand SharePoint list item IDs.
