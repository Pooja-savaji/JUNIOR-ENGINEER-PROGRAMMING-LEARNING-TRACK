# 9.3 SharePoint Document Operations

## About
Learned how to upload, organize, retrieve, download, and manage documents in SharePoint.

## Topics Covered
- File Upload
- File Download
- Metadata
- File Naming
- Folder Organization
- Document Retrieval

## What I Practiced
- Uploaded documents to a SharePoint library.
- Organized files using folders.
- Added document metadata.
- Used clear and meaningful file names.
- Retrieved documents using folders, search, and filters.
- Downloaded and verified documents.

## Key Learning

```text id="k6n2qp"
Upload    → Add File
Download  → Get File
Metadata  → Describe File
Folder    → Organize Files
Search    → Find Document
Retrieve  → Access Required File
```

## Outcome
Can manage SharePoint documents while maintaining proper file organization, naming, and metadata.
