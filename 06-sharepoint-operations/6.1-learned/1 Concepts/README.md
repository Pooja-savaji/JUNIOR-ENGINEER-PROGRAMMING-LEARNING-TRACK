# 9.1 SharePoint Concepts

## About
Learned the basic concepts of SharePoint for storing, organizing, and managing business data and documents.

## Topics Covered
- Sites
- Lists
- Columns
- Views
- Document Libraries
- Folders & Files
- Permissions
- Metadata

## What I Practiced
- Created a training SharePoint structure.
- Created an Employee Training list.
- Added columns and views.
- Created a Training Documents library.
- Organized files using folders.
- Added document metadata.
- Understood basic permissions.

## Key Learning

```text
Site → Main Workspace
List → Structured Data
Column → Data Field
View → Filtered Display
Library → Document Storage
Folder → File Organization
Metadata → Information About Data
Permissions → Access Control
```

## Outcome
Can identify the correct SharePoint object for a given requirement and create a basic SharePoint structure.
