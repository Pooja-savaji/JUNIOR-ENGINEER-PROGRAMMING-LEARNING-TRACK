# 9.5 SharePoint Permissions & Failures

## About
Learned how to manage SharePoint permissions and troubleshoot common access and connection failures.

## Topics Covered
- Least Privilege
- Permissions
- Access Failures
- Connectivity Failures
- Throttling
- Configuration Separation

## What I Practiced
- Simulated unavailable user access.
- Checked Read, Edit, and Full Control permissions.
- Differentiated permission errors from connectivity errors.
- Documented troubleshooting steps.
- Learned how to handle throttling using retry and backoff.
- Understood separation of configuration from application code.

## Key Learning

```text
Permission Error → Check Access
Network Error    → Check Connection
Throttling       → Wait & Retry
Configuration    → Keep Settings Separate
Least Privilege  → Give Minimum Required Access
```

## Outcome
Can diagnose basic SharePoint permission and connectivity issues and document appropriate troubleshooting steps.
