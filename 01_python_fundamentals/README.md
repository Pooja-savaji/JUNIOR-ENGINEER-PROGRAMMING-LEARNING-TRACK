# Python Fundamentals

Core Python syntax, data types, control flow, functions, string manipulation, and standard library tools.

## Included Fundamentals Programs (`learned/`)
- `calculator.py`: Interactive CLI calculator with arithmetic, exponents, square roots, percentages, and calculation history.
- `unit_converter.py`: Multi-category unit converter for length, mass/weight, temperature (C/F/K), storage, and speed.
- `grade_calculator.py`: Weighted course grade calculation, GPA mapping (4.0 scale), batch statistics, and ASCII histograms.
- `menu_cli.py`: Production-grade menu-driven CLI task manager architecture demonstrating interactive loops, validation, and modular action handlers.
- `text_formatter.py`: String case transformations (Title, camelCase, snake_case, kebab-case, PascalCase), slug generation, word wrapping, and text analytics.
