# 4.3 Multi-page Apps

## About
This topic introduces the basic concepts of **Multi-page Apps in Streamlit**. It explains how to organize an application into multiple pages, navigate between pages, reuse UI components, and configure the application.

## Concepts Covered

- Page Organization
- Navigation
- Reusable UI Components
- Configuration

## What I Learned

- Multi-page apps divide a Streamlit application into different pages.
- Page organization makes the application easier to manage and understand.
- Navigation allows users to move between different pages.
- Reusable UI components can be used on multiple pages.
- Configuration is used to set the basic settings of the Streamlit application.

## Learning Outcomes
After completing this topic, I can:

- Organize a Streamlit application into multiple pages.
- Create navigation between different pages.
- Understand how multi-page applications work.
- Create and reuse UI components.
- Configure basic Streamlit application settings.
- Build a simple and well-organized multi-page Streamlit application.
