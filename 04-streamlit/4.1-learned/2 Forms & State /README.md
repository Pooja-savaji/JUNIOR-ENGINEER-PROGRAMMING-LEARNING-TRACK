## 4.2 Forms And State

## About
This topic introduces **Forms and State management in Streamlit**. It explains how to group user inputs, store values during app reruns, use callbacks, validate inputs, and manage changes in application state.

## Concepts Covered

- Forms
- `session_state`
- Callbacks
- Validation
- State Transitions

## What I Learned

- Forms are used to group multiple inputs and submit them together.
- `st.session_state` is used to store data between Streamlit reruns.
- Callbacks allow a function to run when a widget changes or an action occurs.
- Validation checks whether the user input is correct.
- State transitions manage changes from one application state to another.
- Forms and state make Streamlit applications more interactive and organized.

## Learning Outcomes
After completing this topic, I can:

- Create forms to collect user input.
- Use `st.session_state` to store and manage values.
- Create and use callbacks.
- Validate user inputs.
- Manage different application states.
- Build simple interactive Streamlit applications using forms and state.
