## 4.1 Foundation

## About
This topic introduces the basic concepts of **Streamlit** in Python. It explains how to create and run a Streamlit app, use widgets, display text, tables and charts, organize the app layout, and understand the rerun model.

## Concepts Covered

- App Execution
- Widgets
- Text Output
- Table Output
- Chart Output
- Layout
- Rerun Model

## What I Learned

- Streamlit is used to create simple web applications using Python.
- A Streamlit app can be run using the `streamlit run` command.
- Widgets allow users to interact with the application.
- Text can be displayed using Streamlit functions.
- Tables can be used to display structured data.
- Charts can be used to visualize data.
- Layouts help organize content using columns and sidebars.
- Streamlit reruns the script when the user interacts with widgets.

## Learning Outcomes
After completing this topic, I can:

- Create and run a basic Streamlit application.
- Use common Streamlit widgets.
- Display text, tables, and charts.
- Create simple layouts using columns and sidebars.
- Understand how the Streamlit rerun model works.
- Build a simple interactive web application using Python.
