# Internal Operations Dashboard

## About
Built a standalone Streamlit dashboard for internal operations with login, data entry, filtering, and downloadable reports.

## Concepts Covered

- Login
- Data Entry
- Filtering
- Session State
- CSV Download
- Error Handling
- Testing

## What I Learned

- Designed the application flow independently.
- Created a simple login system.
- Added and filtered operation records.
- Generated downloadable reports.
- Handled errors and empty states.
- Added basic tests.

## Learning Outcomes

- Build a complete Streamlit application.
- Manage application state.
- Handle user input and data.
- Create reports and downloads.
- Write basic tests.
- Fix and test application defects.
