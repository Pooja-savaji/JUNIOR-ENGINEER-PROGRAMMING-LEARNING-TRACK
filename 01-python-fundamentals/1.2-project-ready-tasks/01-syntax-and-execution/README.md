# 4.1 Syntax & Execution

## Overview
This section covers the basic syntax and execution concepts required to write, understand, and run Python programs.

## Topics Covered

### 1. Variables
Variables are used to store and manage data in a Python program. A variable can hold different types of values.

### 2. Data Types
Data types define what kind of data is stored in a variable. Common Python data types include strings, integers, floats, booleans, lists, tuples, sets, and dictionaries.

### 3. Expressions
Expressions are combinations of values, variables, and operators that Python evaluates to produce a result.

### 4. Operators
Operators are symbols or keywords used to perform operations on data. Python includes arithmetic, comparison, logical, assignment, and other types of operators.

### 5. Input and Output
Input is used to receive data from the user, while output is used to display information or results to the user.

### 6. Comments
Comments are notes written in the program to explain the code. Python ignores comments when executing the program.

### 7. Indentation
Indentation means the spaces used at the beginning of a line. Python uses indentation to define blocks of code, so correct indentation is important.

### 8. Script Execution
A Python script is a file containing Python code. Script execution means running the Python file so that the instructions inside it are processed by the Python interpreter.

### 9. Modules
A module is a Python file containing reusable code such as functions, variables, or classes. Modules help organize programs and avoid repeating code.

### 10. Imports
Imports allow a Python program to use code from another module. They make it possible to reuse existing Python code in a program.

## Practice Tasks
* Practice using variables and data types.
* Practice expressions and operators.
* Practice input and output.
* Practice writing comments.
* Practice proper indentation.
* Create and run Python scripts.
* Create simple modules.
* Import modules into Python programs.

## Learning Outcome
After completing this section, I understand the basic structure of Python programs and can write, organize, and execute simple Python code using variables, data types, operators, input/output, modules, and imports.
