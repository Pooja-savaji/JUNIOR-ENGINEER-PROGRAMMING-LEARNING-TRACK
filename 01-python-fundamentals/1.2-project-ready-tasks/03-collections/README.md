# 4.3 Collections

## Overview
Collections are used to store and organize multiple values in Python. Different collection types are useful for different types of data and operations.

## Topics Covered

### 1. List
A list is an ordered and changeable collection of items. It allows duplicate values and is useful when the order of data is important.

### 2. Tuple
A tuple is an ordered collection that cannot be changed after it is created. It is useful for storing fixed or unchanging data.

### 3. Set
A set is a collection of unique values. It does not keep duplicate values and is useful when uniqueness is important.

### 4. Dictionary
A dictionary stores data in key-value pairs. It is useful for organizing and accessing data using meaningful keys.

### 5. Indexing
Indexing is used to access a specific item from an ordered collection using its position.

### 6. Slicing
Slicing is used to access a selected portion of an ordered collection. It allows data to be taken from a specific starting position to an ending position.

### 7. Comprehensions
Comprehensions provide a shorter way to create collections by processing or filtering existing data.

### 8. Nested Structures
Nested structures are collections stored inside other collections. They are useful for representing complex or structured data.

### 9. Mutation vs Copying
Mutation means changing the contents of an existing collection.
Copying means creating a separate collection based on another collection.
Understanding the difference helps prevent unexpected changes to data.

### 10. Choosing the Correct Collection
Different collection types are suitable for different situations.

* **List:** Ordered and changeable data.
* **Tuple:** Ordered and fixed data.
* **Set:** Unique data.
* **Dictionary:** Key-value data.

### 11. Complexity and Behavior
Different collection operations have different performance characteristics.
Understanding basic complexity helps in selecting a suitable collection for storing, searching, adding, removing, and accessing data.

## Learning Outcome
After completing this section, I understand Python collections and can choose an appropriate collection based on the type of data, required behavior, and basic performance needs.
