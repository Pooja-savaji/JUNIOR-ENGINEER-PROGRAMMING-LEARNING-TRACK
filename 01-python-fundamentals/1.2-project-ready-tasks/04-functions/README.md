# 4.4 Functions

## Overview
Functions are reusable blocks of code used to perform a specific task. They help organize programs, reduce repeated code, and make programs easier to understand and maintain.

## Topics Covered

### 1. Parameters
Parameters are variables defined in a function that allow the function to receive data when it is called.

### 2. Return Values
A return value is the result that a function sends back to the part of the program that called it.

### 3. Default Parameters
Default parameters allow a function to use a predefined value when a value is not provided for that parameter.

### 4. Keyword Arguments
Keyword arguments allow values to be passed to a function by specifying the parameter name. This makes function calls clearer and allows arguments to be provided in a different order.

### 5. *args
`*args` allows a function to accept a variable number of positional arguments. It is useful when the number of values provided to a function is not fixed.

### 6. **kwargs
`**kwargs` allows a function to accept a variable number of keyword arguments. The arguments are received using their parameter names.

### 7. Scope
Scope defines where a variable can be accessed in a program.

Python mainly works with:
* **Local scope:** Variables created inside a function.
* **Global scope:** Variables created outside functions.
Understanding scope helps avoid unexpected variable changes and naming problems.

### 8. Pure Functions
A pure function produces the same result when given the same input and does not change data outside the function.
Pure functions are easier to understand, test, and reuse.

## Learning Outcome
After completing this section, I understand how to create and use functions with different types of parameters, return values, flexible arguments, scope, and pure functions.
