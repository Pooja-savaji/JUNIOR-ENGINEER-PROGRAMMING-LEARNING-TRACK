# 4.2 Control Flow

## Overview
Control flow determines the order in which Python instructions are executed. It allows a program to make decisions, repeat tasks, and control when a loop should stop or continue.

## Topics Covered

### 1. if / elif / else
These statements are used to make decisions in a program.
* `if` checks the first condition.
* `elif` checks another condition when the previous condition is false.
* `else` runs when none of the conditions are true.

### 2. for Loop
A `for` loop is used to repeat a block of code for each item in a sequence or collection.

### 3. while Loop
A `while` loop repeatedly executes a block of code as long as a given condition remains true.

### 4. range()
`range()` is used to generate a sequence of numbers. It is commonly used with `for` loops when a specific number of repetitions is required.

### 5. break
`break` is used to immediately stop a loop, even if the loop condition has not finished.

### 6. continue
`continue` skips the current iteration of a loop and moves to the next iteration.

### 7. Nested Loops
A nested loop is a loop placed inside another loop. It is useful when a task requires multiple levels of repetition.

### 8. Conditional Expressions
A conditional expression provides a short way to choose between two values based on a condition.

## Practice Tasks
* Practice making decisions using `if`, `elif`, and `else`.
* Practice repeating tasks using `for` loops.
* Practice condition-based repetition using `while` loops.
* Practice generating number sequences with `range()`.
* Practice stopping loops using `break`.
* Practice skipping iterations using `continue`.
* Practice using loops inside other loops.
* Practice writing short conditional expressions.

## Learning Outcome
After completing this section, I can control the execution of Python programs using conditions, loops, ranges, loop controls, nested loops, and conditional expressions.
