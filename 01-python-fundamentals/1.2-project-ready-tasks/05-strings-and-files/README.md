# 4.5 Strings & Files

## Overview
Strings and files are important for working with text and stored data in Python. This section covers string operations, formatting, file paths, different file types, encoding, and safe file handling.

## Topics Covered

### 1. String Operations
String operations are used to work with text. They include finding, changing, joining, splitting, and checking text.

### 2. String Formatting
String formatting is used to combine values with text and create readable output.

### 3. pathlib
`pathlib` is a Python module used to work with file and folder paths. It provides a simple and reliable way to create, check, and manage paths.

### 4. Text Files
Text files store information as plain text. Python can be used to read from and write to text files.

### 5. JSON Files
JSON files store structured data in a format that is commonly used for data exchange. Python provides support for reading and writing JSON data.

### 6. CSV Files
CSV files store data in rows and columns. They are commonly used for spreadsheets, tables, and simple data exchange.

### 7. Encoding
Encoding defines how text is represented as bytes when it is stored or transferred

### 8. Safe File Handling
Safe file handling means working with files carefully to avoid data loss, incorrect paths, permission problems, and unexpected errors.
It includes properly opening and closing files, handling errors, and avoiding unsafe file operations.

### Learning Outcome
After completing this section, I understand how to work with strings and different types of files in Python. I can handle file paths, text, JSON, CSV data, encoding, and basic safe file operations.
