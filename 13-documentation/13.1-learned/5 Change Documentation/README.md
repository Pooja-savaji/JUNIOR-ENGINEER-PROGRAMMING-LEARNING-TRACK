# 16.5 Change Documentation

## About
This project focuses on documenting software changes, including release notes, known issues, migration instructions, and the impact of changes on users.

## Concepts Covered

- Release notes
- Known issues
- Migration notes
- User-impact summary

## What I Learned

- Document new features and bug fixes.
- Identify and record unresolved issues.
- Explain steps for upgrading software.
- Describe how changes affect users.

## Learning Outcomes

- Create clear change documentation.
- Prepare release notes for software updates.
- Document known issues and limitations.
- Explain migration steps between versions.
- Communicate software changes to users.

## How to Use

1. Read the release notes to understand the latest changes.
2. Check known issues before using the application.
3. Follow migration instructions when upgrading.
4. Review the user-impact summary to understand how changes affect your work.
