## Practice Completed

- Checked changes using `git status`
- Added files using `git add`
- Created commits using `git commit`
- Viewed history using `git log --oneline`
- Checked changes using `git diff`
- Undid unwanted changes using `git restore`

- Switched branches using `git switch`
